# Architecture

Pure Rust library (edition 2024, MIT), single package, everything
feature-gated with `default = ["full"]`. Published to the private `sunbeam`
cargo registry; also consumed as a git dependency by tag. As of v3.0.0 there
is **no CLI here** — that lineage lives in the sibling `cli` repo as its
in-tree `sunbeam-sdk` crate (see [interfaces.md](interfaces.md) for the
naming trap).

## Module map (`src/`)

- `auth/` — sso-gateway IAM client (ConnectRPC stubs generated by `build.rs`
  from BSR `buf.build/sunbeamdotpt/sso-gateway`)
- `kanban/` — Kanban ConnectRPC client (stubs from BSR; generated file is
  gitignored)
- `wfectl/` — WFE workflow engine gRPC client (wfe 1.10 crates)
- `search/`, `matrix/`, `media/`, `monitoring/` — g2v-based REST clients
  (OpenSearch, Matrix, LiveKit+JWT, Prometheus/Loki/Grafana)
- `kube.rs`, `manifests.rs`, `manifest_params.rs`, `profiles/` — kube client,
  kustomize apply (global apply `Semaphore(2)` protects single-node k3s)
- `openbao.rs`, `secrets.rs`, `vault_keystore.rs` — OpenBao init/unseal/seed,
  transit keystore crypto
- `vpn/` — daemon control; rewrites cluster URL to loopback proxy when VPN
  is up
- `build/` — BuildKit via host `buildctl` wrapper
- `testing/` — **the load-bearing feature**: testcontainers builders for the
  whole platform (postgres, openbao, opensearch, tuwunel, livekit, stalwart,
  ory stack, openfga, `SsoGateway` orchestrator, …). Consumed by kanban,
  nats-callout, proxy. See [interfaces.md](interfaces.md).
- `error.rs` — `SunbeamError`, `ResultExt.ctx()`, `bail!`; `logger.rs`,
  `logging/` — structured logging (tracing, no `log` crate)
- `config.rs` — `~/.sunbeam/config.json` named contexts (shared with the CLI)

## Build-time machinery

`build.rs` runs `buf export` for auth/kanban codegen (**buf must be on PATH**),
embeds `lima-sunbeam.yaml`, stamps commit/build date. `proto/` vendors Ory
Keto protos (used as an include root) plus kanban proto copies that look like
residue — see [known-issues.md](known-issues.md).
